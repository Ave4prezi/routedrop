# RouteDrop

This repository contains the RouteDrop platform and preview site. The old VIALE website is not present in the current repository files.

## Active RouteDrop branches

- `routedrop-platform-beta` — RouteDrop marketplace application, deployed on Render as `routedrop-platform-beta-av`.
- `routedrop-preview` — RouteDrop preview site, deployed on Render as `routedrop-preview-av`.

The `main` branch contains only repository metadata; RouteDrop application code is intentionally kept on its deployment branches.

**Deployment safety:** Both RouteDrop Render services track their corresponding branches and may deploy automatically after changes. Do not delete, reset, or replace either branch when cleaning up old website content.
